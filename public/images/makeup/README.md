# Makeup Services Folders

This directory contains folders for different specific makeup services:
- `bridal/`
- `engagement/`
- `hd/`
- `airbrush/`
- `party/`
- `reception/`

Place your images inside these subfolders, for example `bridal/look-1.jpg` or `hd/look-1.jpg`, to match the paths in `lib/mock-data.ts`.
