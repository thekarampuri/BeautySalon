# Images Directory

This is the main folder for all static images on the website. To keep things organized, images are grouped into subfolders based on their category:

- `services/`: General services like hair, skin, nail, spa.
- `makeup/`: Specific makeup services like bridal, engagement, HD, etc.
- `courses/`: Academy courses.
- `gallery/`: Portfolio images divided by category (bridal, makeup, hair, etc.)

Please navigate into each of these folders. You will find a `README.md` inside each folder that tells you the exact filenames expected by the website for that specific category.
